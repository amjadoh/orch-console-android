# تطبيق المنظّم (أندرويد)

غلاف **TWA (Trusted Web Activity)** لواجهة المنظّم (`orch-console`). يفتح نفس الواجهة بمحرك Chrome، وكل شي يشتغل منها، ومنه الموافقة بالبصمة (Passkey).

## المتطلبات على الجوال
- **Tailscale شغّال:** السيرفر ما يوصله أحد من برا الشبكة.
- **Chrome مثبت.**

## البناء
- **وين:** GitHub Actions، في الملف `.github/workflows/android.yml`. البناء على السيرفر مقفول.
- **التوقيع:** بمفتاح PKCS12 محفوظ في أسرار المستودع:
  - `ORCH_KEYSTORE_BASE64`
  - `ORCH_KEYSTORE_PASSWORD`
- **الإصدار:** وسم `vX.Y.Z` يسوي Release فيه ملف APK مباشر.
  - رقم النسخة (versionCode) = `X*10000 + Y*100 + Z`.
  - التحديث يثبت فوق النسخة القديمة، لأن المفتاح نفسه.

## ملء الشاشة
- **عشان يفتح بدون شريط عنوان:** لازم السيرفر يقدّم `/.well-known/assetlinks.json` فيه بصمة شهادة التوقيع، وChrome يتحقق منه.
- **القيد:** السيرفر داخل Tailscale بس، فممكن التحقق يفشل. لو فشل، يطلع شريط عنوان رفيع فوق، والتطبيق يشتغل كامل.
